## 简介

这是一个基于Hugo静态网站生成器构建的发布页面项目。该项目使用hugo-bearblog主题，提供了简洁美观的单页发布界面，主要用于展示客户端下载链接、常见问题解答和重要通知信息。

项目特点：
- 基于Hugo静态生成器
- 使用hugo-bearblog主题
- 支持中文显示
- 内置LiveReload功能
- 包含客户服务集成

## 本地开发环境搭建

### 步骤1：安装Hugo

**Windows系统：**
```bash
# 使用Chocolatey包管理器
choco install hugo

# 或者使用Scoop包管理器
scoop install hugo
```

**macOS系统：**
```bash
# 使用Homebrew包管理器
brew install hugo
```

**Linux系统：**
```bash
# Ubuntu/Debian
sudo apt-get update
sudo apt-get install hugo

# CentOS/RHEL/Fedora
sudo yum install hugo
```

### 步骤2：验证安装

```bash
# 检查Hugo版本
hugo version

# 预期输出：Hugo Static Site Generator vX.X.X BuildDate=...
```

### 步骤3：克隆项目仓库

```bash
# 克隆项目到本地
git clone <仓库URL>
cd docs

# 验证项目结构
ls -la
```

### 步骤4：启动本地开发服务器

```bash
# 启动Hugo开发服务器
hugo server

# 或者指定端口
hugo server -p 1313

# 预期输出：Web Server is available at http://localhost:1313/
```

### 步骤5：访问本地站点

在浏览器中打开：`http://localhost:1313`

您应该看到类似以下的界面：
- 标题：更新地址
- 当前可用地址列表
- 重要通知区域
- Hugo主题样式

## 配置文件详解

### 主配置文件：config.toml

**配置文件位置**：`./config.toml`

**核心配置项说明**：

```toml
baseURL = "https://fb.cdnn1.com/"
languageCode = "zh-CN"
title = "发布页"
theme = "hugo-bearblog"
```

**配置项详细说明**：

| 配置项 | 类型 | 默认值 | 描述 |
|--------|------|--------|------|
| baseURL | 字符串 | "" | 网站的基础URL地址 |
| languageCode | 字符串 | "en-us" | 网站语言设置（zh-CN为简体中文） |
| title | 字符串 | "My New Hugo Site" | 网站标题 |
| theme | 字符串 | "" | Hugo主题名称 |

**自定义CSS配置**：
```toml
# [params]
# customCSS = ["css/custom.css"]
```

### 配置文件修改示例

**修改网站标题**：
```toml
title = "我的发布页面"
```

**修改基础URL**：
```toml
baseURL = "https://yourdomain.com/"
```

**启用自定义CSS**：
```toml
[params]
customCSS = ["css/custom.css"]
```

## 常见问题和解决方案

### 问题1：Hugo安装失败

**症状**：`command not found: hugo`

**解决方案**：
```bash
# 检查PATH环境变量
echo $PATH

# 重新安装Hugo
# Windows: 使用管理员权限重新安装
# macOS: brew reinstall hugo
# Linux: sudo apt-get install --reinstall hugo
```

### 问题2：端口被占用

**症状**：`address already in use`

**解决方案**：
```bash
# 更换端口号
hugo server -p 1314

# 或者杀死占用端口的进程
# Windows:
netstat -ano | findstr :1313
taskkill /PID <进程ID> /F

# macOS/Linux:
lsof -ti:1313 | xargs kill -9
```

### 问题3：内容不更新

**症状**：修改内容后页面无变化

**解决方案**：
```bash
# 确保服务器仍在运行
# 检查LiveReload是否工作
# 刷新浏览器页面
# 清除浏览器缓存
```

### 问题4：主题文件缺失

**症状**：页面显示异常或缺少样式

**解决方案**：
```bash
# 确认hugo-bearblog主题已安装
# Hugo 0.148.0版本自带主题
# 检查config.toml中的theme配置
```

### 问题5：中文显示问题

**症状**：中文字符显示为乱码

**解决方案**：
```toml
# 确保config.toml中有正确的语言设置
languageCode = "zh-CN"

# 检查文件编码为UTF-8
# 在编辑器中转换文件编码
```

### 问题6：构建失败

**症状**：`hugo build`命令执行失败

**解决方案**：
```bash
# 检查Hugo版本兼容性
hugo version

# 清理缓存
hugo --cleanDestinationDir

# 检查配置文件语法
hugo --verbose
```
