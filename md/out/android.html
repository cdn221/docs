✅ 安卓客户端 用户使用说明

请使用 Google Chrome 浏览器 下载：

🍎 一、下载安装专属客户端

🔽 apk

  1. 输入你的账号密码登录
  2. 首次连接时系统会提示安装 VPN 配置 → 点击 允许
  3. 点击选择节点：默认使用“自动选择节点”
  4. 点击选择节点，可手动测速并选择延迟最低的节点（右上角闪电图标）
  5. 不使用时请断开连接，以免影响国内应用速度。

🐱 二、下载 通用客户端（备用，当专属客户端不可用时）如果是专属客户端，下面步骤不用再看了

🔽 apk

如果提示防火墙，请点允许

安装步骤： 1）安装 FlClash-0.8.90-android-arm64-v8a.apk 2）打开软件，在回到网站按照方法3导入

⚡ 三、导入配置（推荐一键）

方法 1：一键导入

如果没有成功：多点几次 → 仍不成功尝试方法 2。

✋ 方法 2：手动导入（备用）

1）后台复制 订阅链接 2）打开 FlClash 客户端，配置 3）删除旧配置 → 右下角+号， 4）通过URL获取配置文件 5）粘贴，点击确定

🚀 四、开始使用

点击 FlClash 仪表盘，系统代理打开，右下角点击启用，其他地方保持不变 即可开始使用。

🔍 五、验证成功

访问 https://google.com 能打开 = 配置成功。

🔄 六、开机自启（可选）

右键 FlClash 图标 → 打开 自启动。

⛔ 七、停止代理

右键Flash图标 → 取消 设置为系统代理 → 或者直接点击退出。
