🍎 iPhone / iPad 使用指南（专属客户端）

1. 使用前的重要说明

请务必使用 Safari 浏览器 打开本页面。 不要使用：微信、QQ、Chrome，以免无法正确导入或跳转。

2. 海外 Apple ID 使用规则（必须阅读）

为下载专属客户端，需要使用 海外 Apple ID（共享或付费）。 为确保账号安全，请严格遵守以下规则：

禁止操作（请务必遵循）

不能在“设置”中登录共享 Apple ID 只能在 App Store 登录，否则可能导致：

  • 双重认证被触发
  • 设备锁定
  • 无法退出账号

这些风险与本站无关，请务必注意。

登录时会出现两个提示（必须按此选择）

  1. 第一个提示 → 点击 “其他选项”
  2. 第二个提示 → 点击 “不升级” 绝对不能选择“升级账号安全”。

3. 海外 Apple ID（用于 App Store 登录）

推荐购买更稳定的付费账号（已有海外Apple ID可忽略）：

  • 永久海外 Apple ID（￥12） https://store.kxsw.org/

（购买后请按照商家提供的账号登录 App Store）

4. 如何在 App Store 切换 Apple ID

  1. 打开 App Store

  2. 点击右上角头像

  3. 滑到最底部 → 点击 退出登录

  4. 输入海外 Apple ID 重新登录

  5. 若无法登录，可尝试：

    • 开启飞行模式 → 关闭 → 再尝试
    • 重启设备后再尝试

登录提示处理（必须照做）

  • 出现“Apple ID 安全” → 点击 其他选项
  • 出现“保护你的账户” → 点击 不升级 不要开启双重认证。
