✅ Windows 用户使用说明

请使用 Google Chrome 浏览器 下载：

🍎 一、下载安装专属客户端

🔽 绿色解压版

🔽 exe安装版

如果提示防火墙，请点允许

🐱 二、下载 通用客户端（备用，当专属客户端不可用时）如果是专属客户端，下面步骤不用再看了

🔽 exe安装版

如果提示防火墙，请点允许

安装步骤： 1）右键 Clash.Verge_2.4.3_x64-setup.exe → 2）使用管理员方式安装→ 3）点击桌面快捷方式打开

⚡ 三、导入配置（推荐一键）

方法 1：一键导入

如果没有成功：多点几次 → 仍不成功尝试方法 2。

✋ 方法 2：手动导入（备用）

1）后台复制 订阅链接 2）打开 Clash.Verge 客户端，配置 3）删除旧配置 → 右下角+号， 4）通过URL获取配置文件 5）粘贴，点击确定

🚀 四、开始使用

点击 Clash.Verge 仪表盘，系统代理打开，右下角点击启用，其他地方保持不变 即可开始使用。

🔍 五、验证成功

访问 https://google.com 能打开 = 配置成功。

🔄 六、开机自启（可选）

右键 Clash.Verge 图标 → 打开 自启动。

⛔ 七、停止代理

右键Flash图标 → 取消 设置为系统代理 → 或者直接点击退出。
